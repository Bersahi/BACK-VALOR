📦 ARCHIVOS .BAT DISPONIBLES (Simplificado):

1. iniciar-proyecto.bat      ⭐ PRINCIPAL
   └─> Script interactivo con menú de opciones
   └─> Levanta BD y opcionalmente el backend

2. detener-proyecto.bat
   └─> Detiene todos los servicios

3. reiniciar-db.bat
   └─> Reinicia la BD desde cero (BORRA DATOS)

════════════════════════════════════════════════════════════════

🚀 PARA EMPEZAR:

   1. Asegúrate de que Docker Desktop esté corriendo
   2. Doble clic en: iniciar-proyecto.bat
   3. Espera 1-2 minutos
   4. ¡Listo para desarrollar!

📝 BACKEND API:

   URL: http://localhost:3000
   
   Endpoints:
   - GET    /envios          (Listar todos)
   - GET    /envios/:id      (Obtener por ID)
   - POST   /envios          (Crear nuevo)
   - PUT    /envios/:id      (Actualizar)
   - DELETE /envios/:id      (Eliminar)
